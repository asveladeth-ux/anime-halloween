Anime-inspired greeting website

Files:
- index.html: website page
- assets/background.png: anime-inspired background illustration
- assets/user-audio.mp3: audio extracted from the video supplied by the site owner

Both Yes and No start the supplied audio. The audio loops until the visitor presses the sound toggle.

To publish with GitHub Pages, create a repository, upload all files preserving the assets folder, then enable Pages from Settings > Pages and choose the main branch/root.
